## Vault of Code – Personal To-Do List Application (GUI)

---

## Project Description
description: >
This project implements a Personal To-Do List Application using Python and
the Tkinter GUI library as part of the Vault of Codes Internship. The
application provides a graphical interface that allows users to add, view,
complete, and delete tasks in an organized manner. Task data is stored
permanently using file handling to ensure persistence across sessions.

---

## Objective
objective: >
To design and develop a user-friendly desktop-based To-Do List application
that helps users manage daily tasks efficiently using Python GUI programming
concepts and persistent data storage.

---

## Features
features:

Graphical User Interface built using Tkinter

Add tasks with title, description, and category

Categorize tasks as Work, Personal, or Urgent

Mark tasks as completed

Delete tasks when no longer required

Persistent task storage using JSON file handling

Clean and intuitive user interface design

---

## Tech Stack
tech_stack:

Python

Tkinter (GUI)

JSON (File Handling)

Desktop Application

Visual Studio Code

---

## Application Workflow
application_workflow: >
The user interacts with the application through a graphical interface.
Tasks are added using input fields and displayed in a task list. Users can
mark tasks as completed or delete them using action buttons. All task data
is saved automatically and reloaded when the application restarts.
